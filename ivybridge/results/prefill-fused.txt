# head runs QK-norm, RoPE and the KV cache copy of that head (qkv_item). A
# gate/up chunk is 32 gate rows and the same 32 up rows, followed by SwiGLU and
# the Q8_0 block of these 32 values (gu_item); the block goes to a second slot
